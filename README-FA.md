# عامل کدنویسی محلی (Electron) — ویندوز ۷ به بالا

## گرفتن EXE با GitHub Actions
1. یک مخزن (repo) جدید در GitHub بساز و **محتوای همین پوشه** را در ریشه‌ی آن آپلود کن (پوشه‌ی `.github` هم باید باشد).
2. تب **Actions** ← **Build Windows EXE** ← **Run workflow**.
3. پس از چند دقیقه، از بخش Artifacts فایل `windows-exe` را دانلود کن. داخلش این‌هاست:
   - `ChatbotLocalAgent-Setup-x64.exe` / `-ia32.exe` : نصب‌کننده (**شروع سریع‌تر**، پیشنهادی)
   - `ChatbotLocalAgent-portable-x64.exe` / `-ia32.exe` : بدون نصب (هر بار اجرا کمی کندتر باز می‌شود)
   ویندوز ۳۲ بیتی ← `ia32`، ویندوز ۶۴ بیتی ← `x64`.
   (با ساخت tag مثل `v1.0.0` فایل‌ها به Releases هم اضافه می‌شوند.)

نیازی به نصب Node.js یا Chrome نیست. ویندوز ۷ باید SP1 داشته باشد (Electron 22 آخرین نسخه‌ی سازگار با ویندوز ۷ است).

## استفاده
«⚙ تنظیمات» ← سرویس و کلید API (مدل باید Tool/Function calling داشته باشد) ← «📁 انتخاب پوشه» ← درخواستت را بنویس.

## امکانات
| امکان | توضیح |
|---|---|
| خواندن پوشه/جستجو/عیب‌یابی ایستا | `list_dir`, `read_file`, `search`, `diagnose_project` |
| ویرایش و نوشتن فایل | با تأیید؛ نسخه پشتیبان در `.agent-backups` |
| اجرای فرمان | با تأیید؛ فرمان‌های پرخطر قرمز نمایش داده می‌شوند |
| **Subagent** | ابزار `task`؛ چند تحقیق فقط‌خواندنی هم‌زمان با زمینه‌ی جدا |
| **MCP** | سرورهای stdio در «تنظیمات ← پیشرفته»؛ هر فراخوانی تأیید می‌خواهد |
| **Hooks** | `PreToolUse` (خروج با کد ۲ = مسدود)، `PostToolUse`، `UserPromptSubmit`، `Stop` |
| **تصویر** | دکمه 🖼 یا Paste؛ همچنین ابزار `view_image` برای فایل‌های پروژه |
| **Plan mode** | فقط‌خواندنی؛ بعد از برنامه، دکمه «تأیید برنامه و اجرا» |
| **ویرایشگر** | «باز کردن در ویرایشگر» (VS Code اگر نصب باشد، وگرنه برنامه پیش‌فرض) |
| یادداشت پروژه | فایل `AGENTS.md` یا `CLAUDE.md` در پوشه پروژه به‌عنوان راهنما خوانده می‌شود |
| ZIP | دکمه ZIP یا درخواست از عامل |

### نمونه تنظیم پیشرفته (JSON)
```json
{
  "mcpServers": { "fs": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\proj"] } },
  "hooks": { "PreToolUse": [ { "matcher": "run_command", "command": "node C:\\hooks\\check.js" } ] }
}
```
Hook ورودی را به‌صورت JSON از stdin می‌گیرد. (سرور MCP با `npx` به Node.js روی همان رایانه نیاز دارد.)

## امنیت
فقط روی `127.0.0.1` با توکن تصادفی؛ عامل فقط داخل پوشه‌ی انتخابی کار می‌کند؛ `.env` و کلیدها خوانده/نوشته نمی‌شوند؛ کلید API به‌صورت متن ساده در `%APPDATA%\chatbot-local-agent\config.json` است. Hooks و MCP هر دستوری را اجرا می‌کنند، پس فقط موارد مورداعتماد را بنویس.

## محدودیت‌ها
EXE نهایی و اجرای روی ویندوز ۷ تست نشده است؛ منطق برنامه با Node 22 و مدل ساختگی تست شده (`npm test`، ۳۳ بررسی؛ در Actions هم قبل از build اجرا می‌شود). فایل‌ها امضا نشده‌اند، پس ممکن است SmartScreen/آنتی‌ویروس هشدار بدهد. ادغام کامل IDE (افزونه‌ی VS Code با diff داخل ویرایشگر) ندارد.
