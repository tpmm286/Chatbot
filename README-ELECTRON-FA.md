# Chatbot Coding Agent — Windows Desktop (Electron)

این نسخه رابط React را در Electron اجرا می‌کند و API محلی Express را فقط روی `127.0.0.1` بالا می‌آورد.

## راه‌اندازی در ویندوز
1. Node.js نسخه LTS را نصب کن.
2. پوشه را استخراج کن و در آن PowerShell باز کن.
3. اجرا کن:
   ```powershell
   npm install
   Copy-Item .env.example .env
   ```
4. فایل `.env` را باز کن و یکی از `GEMINI_API_KEY` یا `OPENAI_API_KEY` را تنظیم کن.
5. برنامه را اجرا کن:
   ```powershell
   npm run electron:dev
   ```

## ساخت نصاب ویندوز
```powershell
npm run dist:win
```
فایل نصب در پوشه `release` ساخته می‌شود. نسخه قابل حمل:
```powershell
npm run dist:portable
```

## اجرای بررسی‌های پروژه
دکمه‌های `lint`، `build` و `test` اسکریپت‌های متناظر `package.json` را با npm اجرا می‌کنند. پیش از اجرا، تأیید صریح نمایش داده می‌شود.

**هشدار امنیتی:** اسکریپت‌های پروژه می‌توانند کد دلخواه اجرا کنند. فقط پروژه‌های مورداعتماد را اجرا کن. اجرای فرمان‌ها در پوشه Workspace محدود شده، اما sandbox مستقل سیستم‌عامل نیست. پروژه ناشناس را با دسترسی به فایل‌های شخصی اجرا نکن.

## حساب‌ها و مدیریت کاربران
در اولین اجرا، کد راه‌اندازی ادمین در پنجره‌ای نمایش داده می‌شود. آن را در فرم «راه‌اندازی اولیه سامانه» وارد کن. سپس از پنل ادمین می‌توانی کاربران را بسازی، غیرفعال کنی و رمز آن‌ها را تغییر بدهی. اطلاعات حساب‌ها در فایل محلی `auth.json` داخل پوشه داده برنامه نگهداری می‌شود.

## ذخیره‌سازی
Workspaceها در پوشه داده Electron (معمولاً `%APPDATA%/chatbot-ui-electron-agent/workspaces`) نگهداری می‌شوند.

## محدودیت‌های این بسته
- این نسخه برای استفاده محلی روی یک دستگاه طراحی شده است؛ سیستم مدیریت چندکاربره ادمین‌محور در آن فعال نشده است.
- فایل‌های پروژه و گفتگوها ممکن است در بخش‌های متفاوتی ذخیره شوند؛ برای نگهداری امن، از پروژه‌ها نسخه پشتیبان بگیر.
- بسته هنوز روی ویندوز واقعی Build و تست نهایی نشده است. قبل از استفاده روزمره، در محیط آزمایشی اجرا و بررسی کن.
